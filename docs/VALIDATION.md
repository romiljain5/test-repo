# Validation Helpers

Common input validation functions.

## Functions

- `isEmail(str)` - Validate email format
- `isURL(str)` - Check if string is a valid URL
- `isNumeric(value)` - Check if value is numeric
- `isEmpty(value)` - Check if value is empty (null, empty string, empty array/object)
- `clamp(value, min, max)` - Clamp a number between min and max
